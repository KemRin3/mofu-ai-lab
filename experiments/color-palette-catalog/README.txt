PBM 配色カタログ — HTML版（全192枚）

使い方
  1. ZIPファイルを展開する
  2. index.html をブラウザで開く
  3. インターネット接続不要。ブラウザでローカル表示できます。

機能
  ・スライド表示 / 自動再生 / 再生間隔設定
  ・名前・タグ・メモ検索 / サムネイル一覧 / 左右キー操作
  ・お気に入り（ブラウザが保存を許可する場合）
  ・最大4画像の並列比較
  ・YAMLの配色メモ、色コード、タグ、positiveプロンプトを表示・コピー
  ・オリジナルPNG画像も同梱

対応規則
  画像ファイル名の昇順（image_0001 → image_0192）と
  YAMLブロック name のUnicode文字列降順を1対1に対応。
  画像ファイルから配色名を推定したものではありません。

内容
  index.html   HTMLビューア（カタログデータ埋込、直接開けます）
  catalog.json JSON対応表およびYAML情報
  images/      PNG元画像192枚
  thumbs/      一覧表示用軽量JPEGサムネイル192枚
  *.yaml       元YAMLカタログ
