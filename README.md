# mofu-ai-lab

AI-assisted local AI experiments, benchmarks, tools, and research notes.

This is a public AI research lab repository, not a finished-product repository. It collects practical work around local AI: experiments, benchmarking, debugging and compatibility investigations, optimization research, self-made tools, ComfyUI-related experiments, and reproducible experiment notes.

## AI-assisted operation

This repository is largely operated with AI assistance.

AI agents may handle code implementation, documentation, repository organization,
experiment summaries, debugging, and preparation of public reports.

I mainly define what to build or investigate, run and evaluate the actual experiments,
review the observed results, and decide what is accepted, rejected, or investigated next.

In other words, this is not a traditional hand-coded repository.
It is an AI-assisted local AI research lab where the human sets the direction
and validates what actually happens.

動作確認はしています。理解確認はしていません。
